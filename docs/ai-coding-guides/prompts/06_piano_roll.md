# Prompt 06 - Piano Roll MVP

Implement Piano Roll MVP.

Features:

- Canvas grid
- Add note by double click
- Move note by drag
- Resize note
- Delete selected note
- Scale highlighting
- Chord tone highlighting based on Chord Track
- Velocity display or simple property editor

Acceptance:

- can create a 4-bar melody
- scale snap toggle constrains pitch to current scale
- selected note displays theory explanation
