| Project | 拍子と曲の長さ | Yes | トランスポートの「拍子」は 4/4 と 3/4(6/8 は計算だけ対応し、メトロノームのアクセントとドラムパターンが整うまで選択肢に出さない)。拍子を変えても音・コード・ドラムの拍位置は保ち、小節数は総拍数を新しい小節長で切り上げる(4/4 の 8 小節 = 32 拍 → 3/4 で 11 小節)。セクションは拍位置から小節に換算し、割り切れないときは近い小節に寄せて日本語で知らせる。ドラムは 1 拍 = 4 ステップのまま(4/4=16、3/4=12、6/8=12)。細かいグリッドの打点がこの変換で同じレーン・同じステップに重なるときは、拍に合っていた打点(同じなら強い打点、それも同じなら早い打点)だけを残す。消える打点があるときは変更前に数を示して確認し、確認後に適用して結果をトーストで知らせる。「小節数」は 4〜64 で、短くすると後ろにはみ出す音・コード・ドラム・セクションの数と、新しい終わりをまたぐ音・コードの数を日本語で示して確認し、確認後に前者は削除し後者は終わりで切る(ノートの終わり・曲の長さ・MIDI の終わりが一致する)。曲の終わりと同じ位置で終わるクリップは曲の長さに合わせて伸び縮みする(拍子変更で切り上げた分も含む)。クリップが小節の途中で終わるときドラムグリッドはその小節も表示し、クリップの外のステップは押せない(パターンもクリップの終わりまでだけ置く)。再生中に拍子や小節数を変える(Undo / Redo を含む)と、再生位置から予定を組み直し、終わりの位置とメトロノームのアクセントが新しい値に従う。そのとき再生位置をまたいで鳴っている音は残りの長さで鳴らし直し、途切れない。MIDI を読み込んでファイルの拍子に変わるときも同じ変換を通る(既存ドラムの再グリッド、セクションの換算、注意はトースト)。曲は読み込んだ音が収まるまで伸びるだけで、短くはならない。読み込み全体を含め、どれも Undo 1 段 |

## 2. Chord Track

### 2.1 目的

曲全体の和声設計を可視化し、初心者がコード進行を理解しながら編集できるようにする。

### 2.2 UI要素

- タイムライン上部にコードレーンを固定表示
- 各コードイベントは `小節範囲 / コード名 / 機能 / 色` を持つ
- クリック時に右パネルで以下を表示:
  - コード構成音
  - キー内での度数
  - 機能: Tonic / Subdominant / Dominant / Other
  - 次に進みやすい候補
  - 初心者向け説明

### 2.3 入力仕様

- コード名直接入力: `C`, `Am`, `Fmaj7`, `G7`, `Dm7/G` など
- パレット選択: I, ii, iii, IV, V, vi, viiø
- 候補生成: 現在キーと直前コードから候補表示
- 進行テンプレート: I-V-vi-IV、vi-IV-I-V、ii-V-I など

### 2.4 判定仕様

- コードの構成音をノート番号で管理
- キーに対する度数を算出
- ダイアトニック内/外を判定
- 借用和音・セカンダリードミナントはタグ付け
- 初心者モードでは複雑なタグを折りたたむ

### 2.5 受け入れ条件

- Cメジャーで `C - G - Am - F` を置いたとき、I - V - vi - IV と表示される
- `E7 -> Am` を置いたとき、Amに対するセカンダリードミナント候補として説明できる
- コード変更時、ベース/メロディガイドが更新される

## 3. Piano Roll

### 3.1 目的

MIDIノート編集と同時に、スケール・コード・メロディ作法を学べる画面にする。

### 3.2 表示

- 縦軸: ピッチ
- 横軸: 拍/小節
- ノート: 長方形
- コードトーン: 強調表示
- スケール内音: 通常表示
- スケール外音: 薄色/警告表示
- 解決先候補: ホバー時に表示
- 再生ヘッド: 縦線で現在の再生位置を示す。ピアノロール、ドラムステップ(表示中の小節のみ)、アレンジャー、コードトラックで同じ拍位置・同じ拍幅換算で描く。ピアノロールとドラムステップはクリップの先頭を左端として描くので、再生ヘッドもルーラーの小節番号もクリップの開始位置を差し引いて合わせる。ドラムステップはズームに追従するが、マス目が押しやすい幅(1ステップ 22px)を割らないよう、低いズームではこの幅を下限に広げて描く
- ルーラー: 小節番号の定規。ピアノロール、アレンジャー、コードトラックの上に表示する。コードトラックはルーラーとコードの列を一つの横スクロール領域に入れるので、ズームで画面幅を超えた後ろの小節も横スクロールで表示・クリックできる

### 3.3 操作

- ダブルクリックでノート追加
- ドラッグで移動
- 端をドラッグで長さ変更
- Alt/Option + ドラッグで複製
- Qで量子化
- SでScale Snap切替
- CでChord Tone Highlight切替

ショートカット一覧(定義は `apps/studio/src/state/keymap.ts` の表のみ。アプリ内では `?` キーまたはトランスポートバーの「？」ボタンで同じ一覧を表示する):

| 使える場所 | キー | 動作 |
|---|---|---|
| どの画面でも | Space | 再生/停止 |
| どの画面でも | Ctrl/Cmd+Z | 元に戻す |
| どの画面でも | Ctrl/Cmd+Shift+Z、Ctrl/Cmd+Y | やり直す |
| どの画面でも | Ctrl/Cmd+S | 保存する |
| どの画面でも | ? | ショートカット一覧を開く |
| どの画面でも | Home | 曲の先頭へ戻る |
| どの画面でも | Ctrl/Cmd+← | 1小節前へ戻る |
| どの画面でも | Ctrl/Cmd+→ | 1小節先へ進む |
| ピアノロール | Delete、Backspace | 選んだ音を消す |
| ピアノロール | Q | 選んだ音のタイミングをマス目にそろえる |
| ピアノロール | S | スケールの音だけに吸着する機能の切り替え |
| ピアノロール | C | コードの音を色で示す機能の切り替え |

入力欄(input / textarea / select / contenteditable)にフォーカスがある間とダイアログ表示中は、どのショートカットも発火しない。修飾キーは表のとおり完全一致で判定する(例: Ctrl+C はピアノロールの C として扱わない)。

Undo の単位(ドラッグ 1 回 = Undo 1 段):

- ピアノロールのノート移動・長さ変更、コードトラックのドラッグは、押してから離すまでが 1 段。
- ミキサーとトラック一覧の音量・パン・エフェクトのスライダーは、pointerdown から pointerup までが 1 段。キーボード操作は 1 回の keyup までが 1 段。
- BPM、プロジェクト名、アレンジャーのセクション名・開始小節・長さの入力は、変更から blur または Enter までが 1 段。日本語入力の変換を確定する Enter は段の区切りに数えない。
- 拍子の切り替えは 1 回 1 段。小節数は blur または Enter で確定して 1 段(短くして削除する確認を含めて 1 段)。
- 操作の前後で内容が同じなら Undo の段は増えない。
- ドラッグ中に pointercancel が起きた時やウィンドウがフォーカスを失った時は、操作を取り消して開始前の状態へ戻す。入力欄の編集はウィンドウが切り替わる時も blur で確定する。
- ドラッグ中に Undo/Redo を行うと、開始前の状態へ戻して操作を終えてから、通常の Undo/Redo を 1 段行う。
- 取り消されたドラッグの指やマウスが後から離されても、別の操作の段は区切らない。
- ドラッグ中のノートを Delete で消すと、そこで操作を終える。移動と削除を合わせて 1 段になる。
- ドラッグ中にスライダーで Undo した後は、押しっぱなしのまま動かしても値は変わらない。もう一度押すか、キー操作で再開する。

### 3.4 学習連動

- スケール外音を置いた場合:
  - 初心者モード: 「これはキー外の音です。緊張感として使うか、近いスケール内音に移動できます。」と表示
  - 中級モード: アプローチノート、ブルーノート、クロマチック等の可能性を表示
- コードトーンに着地した場合:
  - 「安定した着地」として説明
- 連続跳躍が多い場合:
  - 「歌いやすさ」観点のアドバイスを表示

## 4. Drum Step Sequencer

### 4.1 目的

初学者がリズムの土台を早く作れるようにする。

### 4.2 MVP仕様

- 1 拍 = 4 ステップ(4/4 は 16 ステップ、3/4 は 12 ステップ)
- レーン: Kick, Snare, Closed Hat, Open Hat, Clap, Perc
- ベロシティ: 3段階または0〜127
- Swing: 0〜60%
- Pattern length: 1/2/4小節

### 4.3 テンプレート

- Four on the floor
- 8-beat pop
- Hip-hop basic
- Game loop basic
- Lo-fi basic

テンプレートは 4 拍の小節で拍位置として定義し、クリップのステップ幅(stepsPerBar ÷ 1 小節の拍数)に換算して並べる。3/4 では 4 拍目にあたる打点(スネアの 4 拍目など)を落とす。拍位置からステップへの丸めはレッスンのドラム判定と同じ規則(`drumBeatToStep`)なので、小節を割り切れないグリッド(古いファイルの 3/4 + 16 ステップ)でも、置いたパターンがそのまま課題の達成になる。

### 4.4 学習連動

- キック: 拍の重心
- スネア/クラップ: 2拍目/4拍目のバックビート
- ハイハット: 細かい時間感覚
- スウィング: 偶数ステップの遅れ

## 5. Bass Assistant

### 5.1 目的

コード進行からベースラインを作る導線を提供する。

### 5.2 生成ルール MVP

| モード | 内容 |
|---|---|
| Root Only | 各コードのルートを拍頭に配置 |
| Root + Fifth | 1拍目ルート、3拍目5度 |
| Walking Simple | ルート、コードトーン、次コードへの経過音 |
| Octave Pulse | ルートとオクターブ反復 |

### 5.3 説明

生成結果には「なぜその音を置いたか」をノート単位で表示する。

例:

- Cコードの拍頭にC: ルート音なので安定する
- Gへ向かう直前にF#を置く: 半音上行でGへ強く進む経過音

## 6. Melody Assistant

### 6.1 目的

コードに合うメロディを作るためのガイドを出す。

### 6.2 MVP仕様

- コードトーン着地ガイド
- スケール内ランダム生成
- 反復モチーフ作成
- コール&レスポンスのテンプレート
- 音域チェック

### 6.3 評価ロジック

| 観点 | 判定例 |
|---|---|
| コード適合 | 強拍にコードトーンがあるか |
| 歌いやすさ | 跳躍が多すぎないか |
| 反復 | 似たリズム/音型があるか |
| 変化 | 完全反復だけで単調になっていないか |
| 解決 | 緊張音が次に解決しているか |

## 7. Arranger

### 7.1 目的

ループを曲構造へ展開する。

### 7.2 セクション

- Intro
- A / Verse
- B / Pre-Chorus
- Chorus
- Bridge
- Outro

### 7.3 操作

- セクションテンプレート追加
- クリップの複製/エイリアス
- セクションごとの密度調整
- ミュート/アンミュートによる展開作成
- 拍子を変えるとセクションは拍位置を保って小節に換算する(4/4 の 4 小節目開始 = 12 拍 → 3/4 の 5 小節目開始)。境界が小節に割り切れないときは近い小節に寄せ、トーストで知らせる。
- 曲を短くすると、新しい終わりより後ろから始まるセクションは消え、またがるセクションは終わりで切る。ノートとコードも同じで、後ろから始まるものは消え、またがるものは終わりで切る。

### 7.3.1 再生ヘッドとシーク

- ルーラーをクリックすると、その小節の頭へ再生位置が移る。Shift+クリックは拍単位。
- 停止中は移した位置から再生が始まる。再生中にクリックすると、いったん止めて新しい位置から再生を続ける。
- 曲の終わり(最後の小節の次)まで移してから再生すると、すぐに止まって先頭へ戻る。
- 「先頭へ戻る」は Home、「1小節前/先へ」は Ctrl/Cmd+←/→(どの画面でも有効)。
- 再生位置の表示は「小節.拍」(1始まり)。
- シークは再生位置(トランスポート状態)の変更なので、元に戻す履歴には積まない。

### 7.4 学習連動

- Intro: 要素を少なく始める
- A: メロディ/モチーフを提示
- Chorus: 音域、密度、コード変化で盛り上げる
- Outro: 要素を減らして終える

## 9. AI Coach

### 9.1 目的

作曲・理論・操作の質問に答え、プロジェクトに即した改善案を返す。

### 9.2 MVP仕様

- API接続なしでも動くルールベース助言を先に実装
- LLM接続はオプション設定
- 送信内容をユーザーに明示
- 音声ファイル送信はデフォルトOFF

### 9.3 禁止/制限

- 既存アーティストや特定曲の模倣を目的にした生成を主要導線にしない
- 著作権のある音源を学習/分離/再利用する機能は注意喚起を表示
- ユーザーのプロジェクトデータを無断送信しない
