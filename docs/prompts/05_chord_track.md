# Prompt 05 - Chord Track

Implement Chord Track MVP.

Features:

- Add chord event by bar
- Edit chord symbol
- Delete chord event
- Analyze chord using theory-engine
- Display degree/function/explanation in TheoryInspector
- Chord Palette with diatonic chords for current key

Tests:

- adding C-G-Am-F in C major displays I-V-vi-IV
- invalid chord symbol shows recoverable error
- changing key updates displayed degrees
